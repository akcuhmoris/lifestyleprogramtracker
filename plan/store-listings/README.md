# Store listings

Drafts of the metadata you'll paste into App Store Connect and Google Play Console when you reach week 11.

| File | Where it lands |
| ---- | -------------- |
| `app-store.md` | Apple App Store Connect — App Information + What's New |
| `play-store.md` | Google Play Console — Store listing + Data Safety form |
| `screenshots.md` | Plan for required device-size screenshots + suggested copy overlays |

## Notes

- Every brand placeholder is in square brackets `[LIKE THIS]`. Search-replace before pasting.
- Apple counts characters strictly. The short subtitle is **30 chars max**.
- Google's full description is **4000 chars max** — paste, don't trim.
- Both stores require a real **support URL** and **privacy policy URL** before you can submit.
